# Manifestos for Peru's 2026 Elections

A Manifesto here is a `Plan de Gobierno`.

The documents are located in the folder **RAW**, they are in the original format preserved at Peru authority on election ([JNE](https://plataformaelectoral.jne.gob.pe/bandeja/filtros))

The PDFs available belong to the parties with elected legislators for the 2016-Congress (any chamber).
